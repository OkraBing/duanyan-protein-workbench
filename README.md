# 端砚·生物蛋白 — 蛋白质工程干湿闭环工作台（原型）

一个**单文件 HTML 原型**，用来表达蛋白质工程里「设计 → 送检 → 回流 → 再设计」这一轮次闭环
在产品上应该长什么样。打开 `index.html` 即可运行，没有后端，没有构建步骤。

> ⚠️ **里面的项目、变体与测定数据全部是演示数据，不是真实实验结果。** 界面右上角常驻「演示数据」标记。
> 这是一个用于讨论产品形态的原型，不是可用于实际研究决策的工具。

## 它表达了什么

工作台以**轮次**为一等对象，一轮里依次是：

| 阶段 | 页面 | 做的事 |
|---|---|---|
| 假设 | 假设 | 把想法写成可判的假设：涉及位点、效应方向与阈值，**判据在看数据之前锁定** |
| 佐证 | 假设 | 文献 / 进化保守性 / 结构 / 本项目历史四类佐证，各自表态为 支持 / 不支持 / 无信息 |
| 可验证性 | 假设 | 按本项目自己的重复测量算出当前测定**能分辨多小的差**；分辨不了的判据直接报警 |
| 设计 | 设计 | 按孔板容量生成批次，硬约束只排除不排序；并审查这批排布能不能把作用归因到位点 |
| 结果 | 结果 | 计算指标与实测指标分列，置信度分档而非精确排名 |
| 送检与回流 | 送检与回流 | 送检清单与门禁、供应商状态、结果回流（含阴性数据）、失败样本录入 |

几条贯穿产品的判断：

- **命中率是第一指标。** 命中 = 主目标达成 **且** 全部约束达成，分母同时给「按有结果」与「按已送检」两种。
- **一轮的出口有四个**：继续 / 重新设计 / 收口去验证 / 收手，不是只有「继续」。
- **测不出来就说测不出来。** 没有重复测量就显示「算不出」，不给看起来像数的占位值。
- **「这一批分不出来」是一个正式结论**，不是空白。

## 怎么用

### 在线
GitHub Pages 页面见本仓库 About 区的链接。

### 本地
下载 `index.html`，双击打开即可。它是一个完整的 HTML 文档，不依赖任何本地服务。

## 两个外部依赖

| 依赖 | 用途 | 取不到时 |
|---|---|---|
| 3Dmol.js（从 cdnjs 加载） | 结构页的三维结构查看 | 页面给出提示，序列、置信度与 PAE 不受影响 |
| 大模型 API（可选，设置页填） | 对话式操作与解读 | 不填则对话功能不可用，其余功能全部可用 |

**关于 API 密钥**：密钥由使用者自己在设置页填写，只存在浏览器的 `localStorage` 里，
不进入本仓库、不上传到任何第三方、不随页面分发。仓库里没有任何密钥。

从线上域名直连第三方 API 会受浏览器跨域策略限制，可能被拦下——这一点尚未实测。
如需在线使用对话功能，正确做法是由后端代理转发，密钥不下发到前端。

## 状态

原型，仍在改。**还没有任何蛋白工程研究员完整走过一轮**，这是它当前最大的风险。
看到不符合真实科研流程的地方，欢迎开 issue 指出来——这正是最有价值的反馈。
